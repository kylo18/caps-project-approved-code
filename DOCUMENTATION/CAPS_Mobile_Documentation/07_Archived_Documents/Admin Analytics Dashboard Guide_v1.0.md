# Admin Analytics Dashboard Guide

Archived version: v1.0  
Original location: `../02_Technical_Documentation/Admin Analytics Dashboard Guide.md`

## Purpose
This early version documented the first admin analytics dashboard guide for CAPS Mobile.

## Initial scope
- Opening the admin dashboard.
- Viewing analytics summary cards.
- Checking student and class performance information.
- Using reports for academic monitoring.

## Early user steps
1. Log in using an authorized admin account.
2. Open the dashboard.
3. Select the analytics section.
4. Review available charts and summary values.

## Earlier limitations
- Detailed chart behavior was not yet fully documented.
- Filters and refresh behavior were only described generally.
- Role differences between admin users were not yet expanded.

## Version control note
This file is kept as an older baseline before the analytics dashboard guide was expanded.
