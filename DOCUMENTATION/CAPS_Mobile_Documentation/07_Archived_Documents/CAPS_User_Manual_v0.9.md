# CAPS User Manual

Archived version: v0.9  
Current file: `../06_User_Manuals/CAPS_User_Manual_v2.0.13.pdf`

## Purpose
This file is an earlier draft version of the CAPS mobile user manual. It was created before the `v1.0` manual outline and before the current published `v2.0.13` PDF.

## Draft overview
CAPS Mobile is used to access academic information through a mobile device. The app provides different screens depending on the user's account type.

## Basic steps

1. Open the CAPS mobile app.
2. Log in using the provided account.
3. Wait for the dashboard to load.
4. Use the available menu items to open classes, records, or support features.
5. Log out after using the app on a shared device.

## Early feature notes

- Login page.
- Main dashboard.
- Class information.
- Assessment or academic result viewing.
- User profile.
- Support or concern reporting.

## Early role notes

At this draft stage, role instructions were still general:

- Students use the app to view academic information.
- Faculty use the app to review class-related information.
- Administrators use the app to review users, reports, and system information.

## Support notes

Users should report problems if:

- They cannot log in.
- Their dashboard does not load.
- Their role or access looks incorrect.
- A feature displays missing or outdated information.

## Draft limitations

- No screenshots were included yet.
- Role workflows were not yet separated into full sections.
- Admin analytics and report instructions were not yet detailed.
- The final PDF formatting and version number were not yet applied.
- The Help Center process was only described in general terms.
