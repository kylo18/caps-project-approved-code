# User Case Documentation

Archived version: v1.0  
Original location: `../02_Technical_Documentation/User Case Documentation.md`

## Purpose
This early version summarized the first mobile user cases for CAPS Mobile.

## Initial user cases
- Student logs in and views dashboard.
- Student opens classes and results.
- Faculty reviews class-related information.
- Program Chair reviews users, subjects, and reports.
- Dean reviews analytics, reports, and support concerns.
- User submits a support concern.

## Early format
Each user case was documented with:

- User role.
- Goal.
- Basic steps.
- Expected result.

## Earlier limitations
- Alternative flows were not yet fully included.
- Role-specific edge cases were still limited.
- Some admin workflows were grouped together.

## Version control note
This archived draft provides an older baseline for comparing the current user case documentation.
