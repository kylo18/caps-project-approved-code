## Frequently Asked Questions

### 1. What is CAPS Mobile?
CAPS Mobile is the mobile application version of the CAPS system. It allows users to access academic-related features based on their assigned role.

### 2. Who can use CAPS Mobile?
The app supports students, faculty, program chairs, deans, and associate deans.

### 3. How do I log in?
Open the CAPS mobile app, enter your registered email and password, then tap the login button.

### 4. What should I do if I cannot log in?
Check if your email and password are correct. If the issue continues, use the support or Help Center feature when available, or contact the system administrator.

### 5. Why do users see different dashboards?
The dashboard depends on the user's assigned role. Each role has different permissions and available screens.

### 6. Can students view assessment results?
Yes. Students can view available results and related academic information when the data is available in the system.

### 7. Can faculty manage class-related information?
Yes. Faculty users can access role-specific class and subject features based on their permissions.

### 8. What is the Help Center for?
The Help Center is used to submit support concerns or report issues encountered while using the mobile app.

### 9. Why does the app need an internet connection?
CAPS Mobile connects to backend services to load user information, academic data, analytics, and support records.

### 10. How are updates handled?
Updates are documented and released through newer versions of the user manuals, FAQ files, and technical documentation.
