# User Status Behavior

Archived version: v1.0  
Original location: `../02_Technical_Documentation/User Status Behavior.md`

## Purpose
This early version documented the first notes for user status behavior in CAPS Mobile.

## Initial status values
- Active.
- Inactive.
- Archived.
- Pending or unverified, when applicable.

## Early behavior notes
- Active users can access role-based features.
- Inactive users may have limited access.
- Archived users should not appear in normal active user lists.
- Status filters help admins manage user records.

## Earlier limitations
- Status transitions were not yet fully explained.
- Role-specific status permissions were not yet detailed.
- Backend and frontend status mapping was not yet expanded.

## Version control note
This archived file shows the initial user status documentation before later updates.
