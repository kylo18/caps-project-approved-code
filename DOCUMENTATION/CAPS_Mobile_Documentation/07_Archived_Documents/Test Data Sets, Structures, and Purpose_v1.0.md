# Test Data Sets, Structures, and Purpose

Archived version: v1.0  
Original location: `../02_Technical_Documentation/Test Data Sets, Structures, and Purpose.md`

## Purpose
This early version listed the basic test data needed to validate CAPS Mobile.

## Initial test data groups
- Student accounts.
- Faculty accounts.
- Admin role accounts.
- Class records.
- Subject records.
- Assessment and result records.
- Support ticket samples.

## Early testing purpose
- Confirm login works for each role.
- Confirm dashboards load correct data.
- Confirm lists and filters display expected results.
- Confirm support forms can be tested.

## Earlier limitations
- Specific test values were not yet fully structured.
- Edge cases were not yet grouped by feature.
- Analytics calculation test cases were not yet complete.

## Version control note
This archive shows the earlier test data documentation before the current version became more detailed.
