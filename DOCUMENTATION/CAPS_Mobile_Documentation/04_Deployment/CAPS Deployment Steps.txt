CAPS MOBILE LOCAL DEPLOYMENT STEPS

PURPOSE:
This guide shows how to run and test the CAPS mobile app locally during development.

IMPORTANT NOTE:
The mobile app itself does not need Docker. Docker is only needed if you want to run the backend, MySQL, and Redis locally.

1. INSTALL REQUIRED TOOLS

- Node.js LTS
- npm
- Expo CLI through the project scripts
- Android Studio or a physical Android device
- Docker Desktop if you will run the backend locally

2. OPEN THE MOBILE PROJECT

    cd FrontendMobile

3. INSTALL DEPENDENCIES

    npm install

4. SET THE MOBILE ENVIRONMENT VALUES

Update `FrontendMobile/.env` before starting the app.

If you are using the local backend:

    EXPO_PUBLIC_API_URL=http://localhost:8000
    EXPO_PUBLIC_AI_SERVICE_URL=http://localhost:8000

If you are using the live backend instead:

    EXPO_PUBLIC_API_URL=http://18.142.190.113:82
    EXPO_PUBLIC_AI_SERVICE_URL=http://18.142.190.113:82

5. START THE LOCAL BACKEND IF NEEDED

If you want the mobile app to connect to your local CAPS backend, start the backend services from the project root:

    docker compose up -d --build backend mysql redis

Then verify the API:

    curl http://127.0.0.1:8000/api/app-version

6. START THE EXPO DEVELOPMENT SERVER

    npm start

This starts Expo Metro in LAN mode.

7. OPEN THE APP ON A DEVICE

If you want to run the app without building an APK yet, use Expo Go:

- Install **Expo Go** on your Android phone from the Play Store
- Run `npm start`
- Scan the QR code shown in the terminal or Expo Dev Tools
- The app will open inside Expo Go through the QR link

If Expo gives you a direct development link, you can also open that link on the same device or copy it into the browser and launch it through Expo Go.

If you want to run it on an emulator instead:

    npm run android

8. VERIFY THE APP IS CONNECTED

- Open the app
- Make sure the login screen loads
- Try logging in with a test account
- Confirm the app can call the backend API
- Check that navigation and protected screens load properly

9. OPTIONAL: CHECK THE API DIRECTLY

If something does not load, test the backend manually:

    curl http://localhost:8000/api/health
    curl http://localhost:8000/api/app-version

10. OPTIONAL: BUILD A RELEASE APK

If you need a downloadable APK instead of a local Expo session:

    node scripts/prepare-android-build.js
    npx expo prebuild --clean
    cd android
    .\gradlew assembleRelease

After the APK is created, copy it to:

    Backend - Deployment/public/apk/CAPS.apk

11. QUICK LOCAL DEPLOYMENT CHECKLIST

- Dependencies installed
- `.env` values set correctly
- Backend running if local testing is needed
- Expo Metro started
- App opens on device or emulator
- Login works
- API routes respond successfully
