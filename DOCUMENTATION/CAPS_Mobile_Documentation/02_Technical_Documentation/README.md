# Mobile Technical Documentation

## Overview
This folder contains technical documentation for the CAPS mobile application. The documents focus on the current `FrontendMobile` implementation and describe mobile-specific features, API usage, analytics, support workflows, and architecture.

## Contents
- `Admin Analytics Dashboard Guide.md` — mobile admin analytics dashboard behavior and user guide
- `API Documentation.md` — mobile API client behavior, endpoint usage, caching, and offline handling
- `Help Center and Support Documentation.md` — Help Center workflows, support ticket submission, and admin review
- `Implemented UI Components and Layout.md` — UI components, layout structure, and shared mobile patterns
- `Issue Reporting Guide.md` — issue reporting process, supported categories, and admin handling
- `Mobile Analytics and Comparison Features.md` — student and admin analytics/leaderboard feature documentation
- `Mobile Filtering Features.md` — filtering behavior across mobile screens and role-specific filters
- `Mobile Setup, Architecture, and Features.md` — mobile project setup, architecture, dependencies, and navigation
- `Test Data Sets, Structures, and Purpose.md` — test data requirements for validating the mobile app
- `User Case Documentation.md` — mobile user flows for each role
- `User Status Behavior.md` — user status values, filters, and actions in mobile user management

## How to use
- Read `Mobile Setup, Architecture, and Features.md` first for the app structure and service layer.
- Use `API Documentation.md` when implementing or debugging mobile backend integration.
- Use `Help Center and Support Documentation.md` and `Issue Reporting Guide.md` for support workflows.
- Use `Mobile Analytics and Comparison Features.md` and `Admin Analytics Dashboard Guide.md` for analytics-related work.

## Notes
- These documents are intended for the mobile app only.
- Do not make changes to files outside this folder unless explicitly requested.
- Keep the documentation aligned with the current `FrontendMobile` source code and API behavior.
